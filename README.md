# Veena Vadini Public School

A premium, modern and highly responsive school website for **Veena Vadini Public School, Padhar, Betul, Madhya Pradesh**.

The website is built with **Next.js, TypeScript, Tailwind CSS and Supabase** and is designed to provide a professional digital presence for the school while also offering a secure CMS/Admin Panel for managing content dynamically.

## School Information

- **School Name:** Veena Vadini Public School
- **Location:** Chhuri Road, Padhar, District Betul, Madhya Pradesh
- **Board:** CBSE Pattern
- **Medium:** Hindi & English
- **Classes:** Nursery to Class 8
- **Tagline:** Empowering Young Minds for a Brighter Tomorrow.
- **Motto:** Dream. Believe. Achieve.

## Admin CMS

The Admin Panel allows authorized school staff to manage:

- Homepage content
- About School
- Leadership details
- Academics
- Facilities
- Faculty
- Gallery
- Events
- Notices
- Announcements
- Admissions enquiries
- Downloads
- Contact information
- Social Media
- SEO settings
- Site settings

Content updates follow this flow:

**Admin Panel → Supabase → Public Website**

This allows normal school content to be updated without editing source code.
